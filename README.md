# Superbowl-Calculation
# 🥣 超级碗热量记录器

> 本工具帮助您轻松记录每餐超级碗热量，同时结合基础代谢、运动消耗，智能计算每日热量缺口，让体重管理更加科学透明。

## ✨ 主要功能

### 📋 一、记录超级碗
<img width="1197" height="1556" alt="screen-1" src="https://github.com/user-attachments/assets/2883fc84-ffe4-4eeb-8faf-ae291c2c4afe" />

#### 1. 选择主菜（超级碗）
- 点击「超级碗名称」下拉菜单，可以看到所有预设菜品及其热量（如：日本七味豆腐超级碗 (187 kcal)）。
- 支持自定义主菜：选择「✨ 自定义主菜」后，可自行填写名称和热量。
- 也可以选择「无 (跳过主菜)」，仅记录配餐。

#### 2. 搭配食材
- 共有 8 个食材分类：碳水、辅助碳水、植物纤维、莎莎、碎碎、酱料、小食、饮料。
- 每个分类均可从预设列表中选择（均显示热量），或选择「✨ 自定义」自行输入名称和热量。
- 所有分类默认均为「无」，您只需按实际搭配选择即可。

#### 3. 其他信息
- **餐别**：根据当前时间推荐显示“午餐”或者显示“晚餐”，也可手动修改。
- **日期**：默认为当天，可更改记录历史日期。
- 选择完毕，页面会实时显示 **本餐预估热量**。

#### 4. 保存记录
- 点击「记录此餐」按钮，当前搭配将被保存到饮食记录列表中。

---

### 🧮 二、基础代谢 & 热量预算

此板块帮助您了解每日热量消耗与剩余可摄入热量，计算热量缺口。
<img width="1185" height="517" alt="screen-2" src="https://github.com/user-attachments/assets/b6cdb0de-2c69-46c2-8ac8-1ed2d0a98ee4" />

#### 1. 基础代谢（BMR）
- 系统自动根据 Mifflin‑StJeor 公式计算 BMR。
- 计算公式:
1. 男性 BMR=10 × 体重kg + 6.25 × 身高cm - 5 × 年龄 + 5;
2. 女性 BMR=10 × 体重kg + 6.25 × 身高cm - 5 × 年龄 - 161;
- 您也可以手动修改 BMR 数值（例如参考体脂秤数据）。

#### 2. 热量预算
- **今日已摄入**：当天所有饮食记录的热量总和。
- **今日运动消耗**：当天所有运动记录的卡路里总和。
- **今日剩余可摄入热量** = TDEE + 运动消耗 – 饮食摄入  
  （TDEE = BMR × 活动系数）
- 所有数值会随您添加/修改饮食及运动记录实时更新。

### 🏃 三、运动记录
<img width="1184" height="452" alt="screen-3" src="https://github.com/user-attachments/assets/77133c37-3bb1-4626-9d58-382cf496991e" />

#### 1. 添加运动
- 选择运动类型：室内跑步、室外跑步、健身、游泳、力量训练、瑜伽，或选择「✨ 自定义」输入名称。
- 填写消耗热量（kcal）和日期（默认为今天）。
- 点击「添加运动」保存。

#### 2. 管理运动记录
- 预览区域显示最近 3 条运动记录，每条均可编辑或删除。
- 点击「更多运动记录」可在弹窗中查看全部记录，并进行编辑/删除。

#### 3. 运动数据备份
- **导出运动数据**：将所有运动记录保存为 JSON 文件。
- **导入运动数据**：从之前导出的 JSON 文件恢复运动记录。

### 📜 五、饮食记录管理
<img width="1212" height="581" alt="screen-5" src="https://github.com/user-attachments/assets/dca548c7-013b-4074-8cd7-41ccf55e1e22" />

#### 1. 记录列表
- 主页默认显示最近 3 条饮食记录。

#### 2. 卡片操作按钮
- **复制**：一键将所选记录的完整搭配（主菜+所有配餐）复制到表单，日期自动设为今天，方便重复用餐。
- **编辑**：将记录内容加载到表单，修改后点击「更新记录」即可保存。
- **删除**：移除该条记录。

#### 3. 更多记录
- 点击「更多饮食记录」打开弹窗，查看全部历史记录，同样支持复制、编辑、删除操作。

---

### 💾 六、数据备份与恢复

#### 全局备份
- **备份全部数据**：将当前所有饮食记录和运动记录导出为一个 JSON 文件。
- **恢复全部数据**：选择之前备份的 JSON 文件，完全替换当前数据。

#### 运动单独备份
- 运动记录板块提供独立的「导出运动数据」和「导入运动数据」，可单独管理运动记录。

> <span style="color: red;">**注意**：所有数据均保存在您浏览器的本地存储中（localStorage），关闭页面不会丢失。但清除浏览器缓存或更换设备会导致数据丢失，建议定期导出备份。</span>
